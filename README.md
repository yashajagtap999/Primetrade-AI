# Crypto Market Sentiment & Trader Behavior Analysis

## 📌 Objective
Analyze relationship between Bitcoin market sentiment (Fear/Greed) and trader behavior using Hyperliquid dataset.

## 📊 Dataset
- Bitcoin Sentiment Dataset (Fear/Greed Index)
- Hyperliquid Trader Execution Data

## 🧹 Steps Performed
- Data Cleaning & Preprocessing
- Data Merging
- Exploratory Data Analysis (EDA)
- Profitability vs Sentiment Analysis
- Win Rate vs Sentiment
- Position Size vs Sentiment
- Buy/Sell Behavior Analysis
- Top Traders Analysis
- Visualizations
- Trading Insights & Recommendations
